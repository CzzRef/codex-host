对话浮层改成这样

截图里两块红圈都是同一类错：Host 控件漂在对话中间，挡住正文和官方按钮。目标不是换皮，是把职责拆开。

你要的

  1. 工作区 / 变更缩成单行浮层，贴在 Composer 正上方。左侧只展示改动文件所在的 Worktree 和分支；右侧展示文件数与对话文件增删统计，并展开具体文件。
  2. 编辑 / 回滚 / Redo 长在选中的那一轮上，做横向 chip，给官方「提交变更」留出右上角。没选中轮次时不出现。
  3. 按钮要有 即时悬浮说明、按下反馈，以及 二次确认。回滚/编辑会丢后续对话，不能一碰就执行。

右侧可以悬停轮次看「⋯」、点轮次选中、悬停按钮看说明、点回滚看确认框；底部「2 个文件」展开列表并悬停看 diff 预览；Composer 右下「工作树 ▾」打开选择器。当前模式是按你截图复原的漂浮层。

怎么实现

  • 工作区节点挂在 document.body 上，用固定定位贴住 [data-codex-composer-root] 顶边并对齐其横向盒子；不再放进 Composer 父节点，避免祖先 transform 让它漂移。
  • 左侧第一枚是核心工作区（线程 cwd，绿点标记，无变更也常驻）；其后每个涉及的 root 各一枚 chip，带该 root 自己的增删；0 行变更的 root 不出现；不在任何已巡检 root 下的绝对路径经 Host extraPaths 解析成 external chip；放不下的 chip 收进 +N。
  • 右侧折叠控件展示文件数和聚合增删，文件列表贴右边向上展开、按 root 分组；悬浮 diff 预览放大到 560×420 以内、贴在列表左侧、可进入滚动，Esc 关闭；点击进入该文件的官方变更展示。原生 Changes / Review 重复区只在文件披露可用时隐藏。
  • 轮次操作仍是 Host 自有节点（不能写进 React transcript），但坐标锚到选中 [data-turn-key] 的顶栏右侧；和官方 summary 按钮撞框时让位。左侧 8px 圆点已去掉：悬停任一轮次时其右上角出现半透明「⋯」chip，点击即选中该轮并展开 编辑 / 回滚 / Redo；滚动、缩放、轮次尺寸变化与 DOM 变更合并到一帧内重定位。
  • 回滚按钮按 Host inspect.rollback 能力位禁用并给出原因（如「此线程只能回滚最后一轮」）；编辑找不到官方铅笔时把本轮提示回填 Composer 并聚焦；文案不再承诺「还原文件」，也不再暗中点官方 Undo。
  • 动作簇只在对话滚动区里活动：长轮次滚过顶边时它贴住对话区上沿，不会漂进标题栏挡住 Share；轮次只剩一条缝或滑到 Composer 之下就隐藏。
  • Redo 是线程级状态：只有 Host inspect 报 historyRedoAvailable（任意长度的回滚之后，整段被回滚的 Session 进同一个槽）才亮；官方 Redo 只给 Codex 自己的线程兜底，外部线程没槽就只提示。
  • 在 renderer-turn-actions.ts 补 hover/active/focus、自定义 tooltip、锚定确认气泡。Edit / Rollback / Redo 都先确认再调现有 Host RPC。
  • 改 renderer-overlay-layout.ts：删掉右栏 conversationRailBox 当主摆放；底栏用 Composer 宽度，动作条用 turn rect。
