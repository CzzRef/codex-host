对话浮层改成这样

截图里两块红圈都是同一类错：Host 控件漂在对话中间，挡住正文和官方按钮。目标不是换皮，是把职责拆开。

你要的

  1. 工作区 / 变更缩成单行浮层，贴在 Composer 正上方。左侧只展示改动文件所在的 Worktree 和分支；右侧展示文件数与对话文件增删统计，并展开具体文件。
  2. 编辑 / 回滚 / Redo 长在选中的那一轮上，做横向 chip，给官方「提交变更」留出右上角。没选中轮次时不出现。
  3. 按钮要有 即时悬浮说明、按下反馈，以及 二次确认。回滚/编辑会丢后续对话，不能一碰就执行。

右侧可以点轮次、悬停按钮、点回滚看确认框。当前模式是按你截图复原的漂浮层。

怎么实现

  • 工作区节点仍插在 [data-codex-composer-root] 前一个兄弟位置，但用固定定位贴住 Composer 顶边；向上展开时不挤动 Composer 或 transcript。
  • 顶部左侧保留变更文件所在 Worktree 与分支；右侧折叠控件展示文件数和聚合增删，文件列表贴右边向上展开，并支持悬浮 diff 预览与点击进入该文件的官方变更展示。原生 Changes / Review 重复区在替代控件可用时隐藏。
  • 轮次操作仍是 Host 自有节点（不能写进 React transcript），但坐标锚到选中 [data-turn-key] 的顶栏右侧；和官方 summary 按钮撞框时让位。
  • 动作簇只在对话滚动区里活动：长轮次滚过顶边时它贴住对话区上沿，不会漂进标题栏挡住 Share；轮次只剩一条缝或滑到 Composer 之下就隐藏。
  • Redo 是线程级状态：只有 Host inspect 报 historyRedoAvailable（回滚最后一轮之后）才亮；官方 Redo 只给 Codex 自己的线程兜底，外部线程没槽就只提示。
  • 在 renderer-turn-actions.ts 补 hover/active/focus、自定义 tooltip、锚定确认气泡。Edit / Rollback / Redo 都先确认再调现有 Host RPC。
  • 改 renderer-overlay-layout.ts：删掉右栏 conversationRailBox 当主摆放；底栏用 Composer 宽度，动作条用 turn rect。

工作区单行浮层、变更文件向上展开、悬浮 diff 预览与原生重复区条件隐藏已进入 renderer-workspace-bar.ts 和自动化测试；Redo / Mapping Store 不在本轮改动范围。
