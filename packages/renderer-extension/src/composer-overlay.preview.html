对话浮层改成钉顶的轮次头部

原来两块浮层——轮次右上角的动作簇、Composer 上方的工作区 bar——合并成一条钉在对话区顶边的「轮次头部」。它不透明、对齐 Composer 列、把首轮往下顶；Composer 上方不再漂任何东西，正文也不再被盖。

你要的

  1. 第一行：「第 n/N 轮」；本轮提示一行省略，只在用户气泡滚到头部之下才出现，点它回到该轮，▾ 展开全文；编辑 / 回滚 / Redo 右对齐，不透明 chip，禁用只压暗文字。
  2. 第二行永远单行：核心工作树 chip（绿点）在前，涉及的 root 各一枚带增删，放不下的进 +N（悬停列出、点击钉住）；右缘「变更 N 个文件」向下展开，本轮文件标「本轮」并排前；悬停文件在头部与 Composer 之间看 diff。
  3. 当前轮由滚动决定：最后一个顶边滑到头部之下的轮次；滚到末尾就是最后一轮。回复进行中整簇禁用并说明；官方编辑打开在本轮时 chip 隐藏，提示槽显示「正在编辑本轮」。

右侧滚动对话区看序号和提示行实时变化；点提示行回到该轮、点 ▾ 看全文；悬停动作 chip 看说明，点回滚看确认；点右缘「变更 8 个文件」向下展开、悬停文件看 diff；悬停 +N 看被折叠的仓库；Composer 右下「工作树 ▾」打开草稿选择器。「旧浮层」模式复原旧问题：动作簇压住首轮提示，半透明 bar 盖住对话最后几行。

怎么实现

  • renderer-turn-header.ts 把头部挂在 body 上固定定位：turnHeaderBox 取滚动区顶边（标题栏之下）与 Composer 列的并集，reserveTranscriptTop 给对话内容列补 padding-top，首轮滚到顶也不被盖；留不出空间就卸载。
  • 当前轮：resolveCurrentTurn 按 rect 二分——最后一个顶边 ≤ 头部底边的轮次，末尾在视口内取最后一轮，6px 迟滞防抖；promptPinned 只在用户气泡底边滚过头部底边时把提示搬进头部。滚动、resize、ResizeObserver 与 DOM 变更合并到一帧。
  • 第一行由 renderer-turn-header-row.ts 绘制，动作簇仍是 renderTurnActionCluster，状态与 Host RPC 在 renderer-turn-action-controller.ts：回复进行中给 blocked.busy，官方编辑模式让位，回滚能力位不足时诚实禁用，Redo 是线程级槽；tooltip 在头部里向下展开。
  • 第二行由 renderer-turn-header-workspace.ts 从 renderer-workspace-files-state.ts 绘制：fitWorkspaceChips 保证单行、尾部 chip 收进 +N、核心 chip 永不隐藏；renderFileDisclosure 按 root 分组、本轮文件带标签排前；previewOrigin 把 diff 预览放在列表旁、头部之下、Composer 之上。原生 Changes / Review 重复区只在文件披露可用时隐藏。

本轮状态

轮次头部已落地：renderer-turn-header.ts 及其 row / workspace 子模块、turn-header.css、workspace-surface.css；旧的 Composer 上方状态栏与轮次右侧动作簇（含 hover「⋯」）已删除；「工作树 ▾」选择器（renderer-draft-worktree-picker.ts）与多轮回滚 / Redo（Host external-thread-rollback.ts）不变。真机量测项见 vibe/specs/260903/1631-transcript-turn-header/。
